# World Population Analytics – SQL Project

## 📌 Project Overview
This project analyzes global population data using **SQL Server** to identify demographic trends, population growth patterns, and regional comparisons across countries and continents.

---

## 🎯 Problem Statement
Understanding population growth and distribution is critical for policy planning, economic development, and resource allocation.  
This project answers key analytical questions using SQL to explore population changes across regions and time.

---

## 🗂 Dataset Description
The dataset includes country-level population data with attributes such as:
- Country name  
- Continent  
- Population figures  
- Year-wise population growth  

The data is structured to simulate real-world demographic datasets.

---

## 🛠 Tools & Technologies
- SQL Server  
- T-SQL  
- Aggregations & Joins  
- Window Functions  
- Analytical Queries  

---

## 📊 Key Questions Answered
- Which countries have the highest population?  
- Which continents contribute most to global population?  
- How has population grown over time?  
- Which countries show the fastest population growth?  
- What is the population distribution by continent?

- Database and table creation  
- Data aggregation and grouping  
- Ranking and window functions  
- Trend analysis
